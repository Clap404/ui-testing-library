## carriers — BO shipping carriers page for PS 8.2 + version chain

Adds the carriers list and create/edit pages for PS 8.2, and wires up the
version chain so older PS versions get the correct implementation.

### New files
- `src/versions/8.2/pages/BO/shipping/carriers/create.ts` — Full create/edit carrier
  form implementation for the legacy wizard UI (PS < 9). Selectors and methods
  use class properties throughout (no inline strings in method bodies).
- `src/versions/8.2/pages/BO/shipping/carriers/index.ts` — Carriers list page for PS 8.x

### New version-chain files (inherit from nearest newer version)

  (legacy PS uses a configuration form step instead of a direct link)
